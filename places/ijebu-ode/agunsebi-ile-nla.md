# Agunsebi / Ile-Nla Control Case

## Source forms to preserve

- AGUSHENBI — form observed on a Fusengbuwa membership card
- AGUSENBI — attested variant
- AGUNSEBI — widely used contemporary form
- ILE-NLA / ILE NLA — compound designation
- ULE — Ijebu house/home form in linguistic documentation

## Functional hierarchy

Working model:

```text
IJEBU-ODE
  ↓
AGUNSEBI
  ↓
ILE-NLA COMPOUND
  ↓
PARTICULAR ULE / ANCESTRAL HOUSE
  ↓
DESCENT GROUP / OCCUPANTS
```

## Use as control case

This is a comparison case for distinguishing:

- lineage/dynasty,
- ancestral house,
- compound,
- locality,
- polity.

It does not establish genealogical identity with any similarly named place elsewhere.
