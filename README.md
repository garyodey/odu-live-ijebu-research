# ODU.LIVE — Ijebu Constitutional Research

A public, reusable research repository for documenting Ijebu constitutional institutions, ruling-house structures, settlement topology, linguistic forms, and source evidence.

## Scope

This repository currently focuses on:

- AKIJA of Ikija and the Akija succession constitution
- OLISA, ILAMUREN, PAMPA, OSUGBO, and ODI as distinct institutional nodes
- Fusengbuwa / Ile-Nla / Agunsebi as a control case for lineage-house-place distinctions
- Ijebu linguistic forms such as ULE / ILE / ILẸ and orthographic variants
- Evidence-state handling for archival documents, legal declarations, oral traditions, and graphemic observations

## Core safeguards

1. SAME_FORM != SAME_ENTITY
2. G_MATCH != IDENTITY_MATCH
3. OFFICE != PERSON != PLACE != LINEAGE != STYLE != RULER_CLASS
4. UNMARKED_YORUBA_MUST_NOT_COLLAPSE_TONAL_IDENTITY
5. DIALECT_NORMALIZATION_MUST_NOT_CREATE_OR_DESTROY_IDENTITY
6. PROPERTY_EQUIVALENCE_MUST_NOT_COLLAPSE_ENTITY_IDENTITY
7. PRESERVATION_IS_PROPERTY_SPECIFIC
8. A pleading, article, or archival table is not a judicial finding unless a court has actually decided the point.

This repository records public and historical research. Private family material is excluded unless separately approved for publication.

Research repository. It is designed to preserve claims and evidence states rather than to force unresolved disputes into a single narrative.
